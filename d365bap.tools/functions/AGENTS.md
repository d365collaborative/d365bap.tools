# Public functions

Comment-based help must never document the automatic ShouldProcess parameters.
Do not write `.PARAMETER Confirm` or `.PARAMETER WhatIf` blocks. PowerShell
and platyPS document those on their own. `Help.Tests.ps1` treats them as
common parameters and skips them.

A hand-declared `-Force` switch is a real parameter: document it with a
`.PARAMETER Force` block like any other parameter.

Do not hand-edit `*.Tests.ps1` files. They are generated by
`build/generate-parameterunittests.ps1`, which automatically drops the
`Confirm` and `WhatIf` parameter tests. A hand-declared `-Force` switch is
part of the cmdlet signature and keeps its generated test. Always run the
full regeneration after a parameter signature change and include it in the
commit.
